Coleccion de recursos externos utiles para pentesting y CTFs.

### Wikis y cheatsheets generales

- https://deephacking.tech — Recurso comunitario con guias y cheatsheets de hacking.
- https://book.hacktricks.wiki — La referencia mas completa de tecnicas de pentesting y escalada de privilegios.
- https://www.verylazytech.com/ — Cheatsheets rapidos para distintas fases de pentesting.
- https://ahmed-tarek.gitbook.io/ — Notas y writeups de pentesting y AD.

### Busqueda de binarios explotables

> Consulta estos sitios cuando encuentres un binario con SUID, capabilities o permisos de sudo.

- https://gtfobins.org/ — Binarios de Linux explotables para escalada de privilegios, file read, shells, etc.
- https://lolbas-project.github.io/ — Equivalente a GTFOBins pero para binarios nativos de Windows (Living Off The Land).
- https://wadcoms.github.io/ — Buscador interactivo de comandos ofensivos para entornos Windows/AD.

### Articulos y writeups

- https://www.hackingarticles.in/ — Articulos detallados sobre tecnicas de pentesting, CTFs y herramientas.
